개인정보처리방침

01   개요

서울2033 리더(이하 "앱")는 모바일 게임 서울2033의 인카운터 텍스트를 인식하여 나무위키 관련 항목을 자동으로 안내하는 보조 도구입니다.

본 방침은 앱이 사용하는 권한과 데이터 처리 방식을 투명하게 안내합니다.

02   수집하는 정보

앱은 아래 정보만 처리하며, 그 외 어떠한 개인정보도 수집하지 않습니다.

  • 서울2033 게임 화면에 표시된 텍스트 (인카운터 본문)
  • 앱 설정값 (버튼 위치, 투명도 등) — 기기 내부 저장소에만 저장

수집된 텍스트는 나무위키 URL 매칭에만 사용되며, 외부 서버로 전송되지 않습니다. 모든 처리는 사용자의 기기 안에서만 이루어집니다.

03   접근성 서비스 (AccessibilityService)

앱은 게임 화면의 텍스트를 읽기 위해 Android 접근성 서비스를 사용합니다.

  • 사용 목적: 서울2033 화면의 인카운터 텍스트 추출
  • 수집 범위: 서울2033 앱 화면에 표시된 텍스트에 한정
  • 외부 전송: 없음
  • 기타 앱 접근: 없음 (서울2033 패키지에 한정하여 동작)

접근성 서비스는 위 목적 외에 사용자 설정 변경, 다른 앱 모니터링, 개인정보 수집 등의 용도로 사용되지 않습니다.

04   오버레이 권한

앱은 게임 화면 위에 버튼과 팝업을 표시하기 위해 다른 앱 위에 표시(SYSTEM_ALERT_WINDOW) 권한을 사용합니다. 이 권한은 UI 표시 목적으로만 사용되며 다른 앱의 데이터에 접근하지 않습니다.

05   인터넷 사용

앱은 아래 목적으로만 인터넷을 사용합니다.

  • 팝업 내 나무위키 페이지 표시 (WebView)
  • GitHub API를 통한 앱 업데이트 확인

사용자의 텍스트, 설정, 식별 정보는 어떠한 경우에도 외부로 전송되지 않습니다.

06   제3자 제공 및 공유

앱은 수집한 정보를 제3자에게 제공하거나 판매하지 않습니다. 광고 SDK, 분석 SDK, 외부 데이터 수집 서비스를 포함하지 않습니다.

07   데이터 보관 및 삭제

앱이 처리하는 게임 텍스트는 URL 매칭 후 즉시 폐기되며 저장되지 않습니다. 설정값은 앱 삭제 시 기기에서 완전히 제거됩니다.

08   아동 개인정보

앱은 만 14세 미만 아동으로부터 의도적으로 개인정보를 수집하지 않습니다.

09   방침 변경

본 개인정보처리방침이 변경될 경우 본 페이지를 통해 공지합니다. 중요한 변경사항이 있는 경우 앱 업데이트 시 안내합니다.
